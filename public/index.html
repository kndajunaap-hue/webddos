NETWORK TOOLS

Subdomain gratis

Gunakan DDNS untuk memberi nama tetap pada IP yang berubah. Setup dilakukan di provider, token tidak diminta atau disimpan oleh aplikasi ini.

⌁
PILIHAN GRATIS

DuckDNS

DuckDNS menyediakan subdomain DDNS gratis dan endpoint HTTPS untuk memperbarui alamat IP. Daftarkan nama subdomain di situsnya, lalu pasang updater pada server atau router milikmu.

Buka DuckDNS ↗Dokumentasi API

Alur setup

  1. Buat akun dan pilih nama subdomain di DuckDNS.
  2. Pasang updater resmi pada mesin atau router milikmu.
  3. Simpan token hanya di perangkat/server sendiri; jangan kirim ke chat atau unggah ke repositori publik.
  4. Pastikan layanan yang kamu publikasikan memakai autentikasi dan firewall yang sesuai.

Fitur ini memberi panduan saja. Pembuatan otomatis dan pengelolaan DNS belum terhubung ke akun provider.

DEVELOPER

API Access

Buat key rahasia untuk menghubungkan LeoAI ke aplikasi lain melalui format chat completions.

Buat API key

Key hanya ditampilkan sekali. Simpan di backend aplikasimu sebagai secret.

OpenAI-compatible request
fetch('https://YOUR-DOMAIN/api/oracle', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer YOUR_LEO_API_KEY'
  },
  body: JSON.stringify({
    model: 'leoai-free',
    messages: [{ role: 'user', content: 'Halo!' }]
  })
});

Panggil endpoint dari server milikmu, bukan langsung dari browser. Jangan pernah commit API key ke source control.
